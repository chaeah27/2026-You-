# 유레카 리서치 프로그램 연구 아카이브 | Eureka Research Program Archive

학교 감각 환경(시각·청각·후각), 정서(쾌·불쾌/각성), EDA·심박수, 실제 대화 및 대인 호감 연구를 체계적으로 기록하는 **GitHub Pages용 정적 사이트**입니다.

## 바로 실행
- `index.html` 파일을 브라우저에서 여세요. 또는 로컬 서버로 호스팅하세요.
- 연구 일지 / 장비 보정 / 실험 세션 / 분석 / 참고문헌 메뉴에서 기록을 관리하세요.
- 반드시 **데이터 백업** 메뉴에서 JSON 파일을 주기적으로 다운로드하세요.
- 세션 데이터는 CSV로도 추출할 수 있습니다.

## GitHub Pages에 게시
1. 현재 저장소 `chaeah27/2026-You-`를 사용합니다.
2. 압축을 푼 폴더의 `index.html`, `style.css`, `app.js`, `README.md` 등을 저장소 **최상위 경로**에 업로드하세요.
3. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` / `/(root)` → `Save`.
4. 공개 URL은 보통 `https://chaeah27.github.io/2026-You-/` 형태입니다.

## 보안과 데이터 저장에 대한 경고
- 브라우저에 적은 기록은 **그 브라우저의 localStorage에만 저장**됩니다. GitHub, 다른 컴퓨터, 다른 팀원과 **자동 동기화되지 않습니다**.
- localStorage는 암호화된 연구자료 보관소가 아닙니다. 다른 사람이 같은 브라우저 프로필을 쓰면 기록을 읽을 수 있습니다.
- GitHub 공개 저장소에는 실명, 학번, 동의서, 민감정보, 개별 HR/EDA 원시 신호, 비식별화가 불충분한 참가자 데이터 등을 업로드하지 마세요.
- 참가자 코드를 사용하더라도 조합된 정보로 재식별될 수 있습니다. 홈페이지에는 공개 가능한 요약과 절차만 게시하세요.
- 실제 민감 데이터는 학교가 허용한 접근 제한·암호화된 저장소에서 관리하세요.

## 데이터 구조
- `journal`: 연구 일지
- `equipment`: 장비 및 보정 기록
- `sessions`: 익명화된 실험 세션 요약
- `results`: 분석 메모
- `references`: 추가 참고문헌

## 연구 설계 유의사항
- SAM은 쾌·불쾌/각성의 주관적 정서 측정 도구이며, 임의의 숫자 설문은 SAM 원본 사용과 구분해야 합니다.
- EDA·심박수만으로 긍정/부정 정서를 판별할 수 없습니다.
- HRV를 분석하려면 박동 간격 데이터와 적절한 안정 측정 구간이 필요합니다.
- Grove GSR의 저항→전도도 변환은 제조사 보정 지침과 실기 검증이 필요합니다.
- 평균과 막대그래프는 기술통계일 뿐 통계적 유의성, 대화 상대 효과, 인과성을 자동 분석하지 않습니다.

## 커스터마이징
- `style.css`: 색상·글꼴·레이아웃
- `app.js`: 메뉴별 설명 및 입력 양식
- `index.html`: 전체 레이아웃과 메뉴

외부 라이브러리 없이 실행되며 유료 호스팅이 필요하지 않습니다(단, GitHub 정책과 계정 요건에 따름).
